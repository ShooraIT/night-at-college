# 🌙 Ночь в колледже

Интерактивный мастер-класс по HTML, CSS и JavaScript. Колледж опустел после пар. Собери окна, добавь тёплое свечение и напиши код, который погасит каждое окно по клику.

**[Открыть практикум](https://shoorait.github.io/night-at-college/)**

## 🦊 Помощник КЭШ

<img align="right" width="150" src="fox-guide.png" alt="КЭШ в оранжевой толстовке машет лапой">

| Этап | Что сделать | Что появится на экране |
| :--- | :--- | :--- |
| 🧱 **HTML** | Добавить одну или больше кнопок с классами `window lit` внутрь `.building` | На фасаде появятся все добавленные окна |
| 🎨 **CSS** | Написать правило `.window.lit` для фона и свечения | Все окна будут светиться при запуске |
| 💡 **JavaScript** | При клике убрать `lit` у выбранного окна | Окна можно будет погасить по одному |

КЭШ всегда рядом с заданием. Нажми **«Спросить КЭШа»**, чтобы открыть облачко, затем **«Следующий шаг»**, чтобы продвигаться по инструкции.

## 🛠️ Как работать

1. Попробуй погасить окна в готовом примере, затем выбери этап и напиши свой код в редакторе.
2. Нажми **«Запустить»** или **Ctrl/⌘ + Enter**. Сцена обновится справа, а сообщения и ошибки появятся в консоли.
3. Наведи мышь на любой фрагмент кода или поставь на него текстовый курсор и нажми **Alt + I**. Редактор объяснит назначение конструкции, значения или символа.
4. Нажми **«Проверить»**. Черновик и прогресс сохраняются в текущем браузере, если включено локальное хранилище.

В подсказках к примеру `moon` — это луна в правом верхнем углу, `#344c71` — синее стекло погашенного окна, а `win` — одно окно из списка. В HTML можно отдельно навести на `window` и `lit` внутри одного атрибута `class`.

## 📦 Локальный запуск

Скачай репозиторий архивом и распакуй его. Открой `index.html` в браузере. CSS, JavaScript и иллюстрации должны лежать рядом с HTML-файлом.

| Файл | Назначение |
| :--- | :--- |
| [`index.html`](index.html) | Разметка страницы и подключение файлов |
| [`styles.css`](styles.css) | Оформление страницы, редактора, подсказок и анимации КЭШа |
| [`app.js`](app.js) | Редактор, учебные примеры, запуск кода и проверки |
| [`campus-night.jpg`](campus-night.jpg) | Иллюстрация ночного колледжа |
| [`fox-guide.png`](fox-guide.png) | Лис-помощник КЭШ |
