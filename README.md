# 🌙 Ночь в колледже

Интерактивный практикум по HTML, CSS и JavaScript. Колледж уже опустел после пар. Собери окна, добавь тёплый свет и подключи выключатель, чтобы зажечь аудиторию.

**[Открыть практикум](https://shoorait.github.io/night-at-college/)**

## 🦊 Маршрут с Лисом

<img align="right" width="150" src="fox-guide.png" alt="Лис в оранжевой толстовке машет лапой">

| Этап | Что сделать | Что появится на экране |
| :--- | :--- | :--- |
| 🧱 **HTML** | Добавить три элемента `.window` внутрь `.building` | На фасаде появятся окна |
| 🎨 **CSS** | Написать правило `.window.lit` для фона и свечения | Окна смогут загораться |
| 💡 **JavaScript** | Обработать клик и переключать класс `lit` у окон | Кнопка «Свет» будет зажигать и гасить окна |

Открой **«Спросить Лиса»**, чтобы узнать, в какой вкладке работать, какую строку найти и какой код дописать. Каждый шаг показывает нужный фрагмент и объясняет, как проверить результат.

## 🛠️ Как работать

1. Выбери этап и напиши код в редакторе.
2. Нажми **«Запустить»** или **Ctrl/⌘ + Enter**. Сцена обновится справа, а сообщения и ошибки появятся в консоли.
3. Наведи курсор на знакомую по заданию конструкцию или поставь на неё текстовый курсор и нажми **Alt + I**, чтобы увидеть объяснение.
4. Нажми **«Проверить»**. Черновик и прогресс сохраняются в текущем браузере, если включено локальное хранилище.
